# 17: 依赖清理

**What to build:** 三个直接声明的依赖在全仓库零引用：后端的日志美化包、前端直接声明的校验库（前端只通过共享包间接使用）、一个测试库（仅是另一个库的传递依赖）。它们让安装体积变大、也让"项目用了什么"变得不准。做成：移除零引用依赖，并在 CI 中加一道检查防止再次回流。

**Blocked by:** 02 CI 质量门

**Status:** ready-for-agent

- [ ] 三个零引用依赖已从各自的声明中移除
- [ ] 安装结果与锁文件同步更新，可重复安装
- [ ] 类型检查、全部测试、构建均保持通过（证明移除是安全的）
- [ ] CI 中新增一道检查：声明了但未被引用的依赖会让流水线失败
- [ ] 检查机制本身不会误报间接使用的情况（共享包对前端的依赖属于合法用法）

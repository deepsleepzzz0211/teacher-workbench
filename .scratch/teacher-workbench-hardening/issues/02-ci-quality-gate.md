# 02: CI 质量门

**What to build:** 目前 231 条用例只能靠人肉记得跑，README 里的质量声明没有任何强制力。加上 CI：每次推送自动安装依赖、类型检查、跑全部单元与集成测试、跑构建，任一环节失败即标红。此后任何改动都必须先过这道门。

**Blocked by:** 01 初始化版本控制

**Status:** ready-for-agent

- [ ] 推送或提 PR 时自动触发流水线
- [ ] 流水线依次执行：依赖安装（锁定版本）→ 类型检查 → 全部单元与集成测试 → 构建
- [ ] 任一环节失败则整体失败，并在结果中指明是哪一步
- [ ] CI 环境下的后端测试能连上数据库（用服务容器或等价方式），不依赖本机已装 PostgreSQL
- [ ] 故意制造一次类型错误，确认流水线确实变红（验证门禁有效，而非只写了配置）
- [ ] 修复该错误后流水线恢复绿色

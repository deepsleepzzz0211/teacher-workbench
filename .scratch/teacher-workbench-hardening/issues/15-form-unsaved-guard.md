# 15: 表单弹窗未保存保护

**What to build:** 八个业务弹窗（授课任务、其它工作量、成果、企业实践、调课申请、审批意见、待办、发布通知）在点取消、按 ESC、点遮罩时都会立刻关闭，正在填写的内容直接消失。授课任务表单有十几个字段，误触代价很高。做成：表单有未保存改动时，关闭前先确认；没有改动时照常直接关闭，不增加多余点击。

**Blocked by:** None（可立即开始）

**Status:** ready-for-agent

- [ ] 表单有改动时点取消 / 按 ESC / 点遮罩，先弹出确认，用户可选择继续编辑或放弃
- [ ] 表单没有改动时，关闭行为与现在完全一致（不弹确认）
- [ ] 保存成功后关闭不弹确认（这是已保存，不是未保存）
- [ ] 覆盖全部八个弹窗，不遗漏
- [ ] 打开即回填的编辑场景，在用户未改动时关闭不弹确认
- [ ] 新增组件测试：至少覆盖"有改动弹确认"与"无改动不弹"两条
- [ ] 全量测试与类型检查保持绿色

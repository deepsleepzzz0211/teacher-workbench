# 15: 表单弹窗未保存保护

**What to build:** 八个业务弹窗（授课任务、其它工作量、成果、企业实践、调课申请、审批意见、待办、发布通知）在点取消、按 ESC、点遮罩时都会立刻关闭，正在填写的内容直接消失。授课任务表单有十几个字段，误触代价很高。做成：表单有未保存改动时，关闭前先确认；没有改动时照常直接关闭，不增加多余点击。

**Blocked by:** None（可立即开始）

**Status:** done

- [x] 表单有改动时点取消 / 按 ESC / 点遮罩，先弹出确认，用户可选择继续编辑或放弃
- [x] 表单没有改动时，关闭行为与现在完全一致（不弹确认）
- [x] 保存成功后关闭不弹确认（这是已保存，不是未保存）
- [x] 覆盖全部八个弹窗，不遗漏
- [x] 打开即回填的编辑场景，在用户未改动时关闭不弹确认
- [x] 新增组件测试：至少覆盖"有改动弹确认"与"无改动不弹"两条
- [x] 全量测试与类型检查保持绿色（shared 83 / api 160 / web 25 条用例全通过，E2E **22/22**）

**实现说明：** 抽出一个共享的未保存守卫，以表单的"是否被触碰过"作为判断依据——因此"打开即回填但未改动"不会误弹确认，而"保存成功后的关闭"也不走该路径（保存是显式关闭，不是放弃）。七个基于表单的弹窗接入该守卫；审批意见弹窗没有表单，按其输入内容的空/非空做了等价的轻量判断。

**连带修正：** 截图脚本里原先直接点"取消"关闭已填写的弹窗，现在会先弹确认，已同步更新脚本以免截图流程中断。

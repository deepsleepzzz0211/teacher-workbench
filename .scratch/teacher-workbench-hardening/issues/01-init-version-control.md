# 01: 初始化版本控制

**What to build:** 这个项目目前没有任何版本控制，一次误改无法回滚、改动无法审阅。初始化仓库并完成首个提交，让后续每一条工单的改动都可 diff、可回滚、可追溯。

**Blocked by:** None（可立即开始）

**Status:** ready-for-agent

- [ ] 仓库已初始化，且存在一个包含当前全部源码的首个提交
- [ ] 环境变量文件未被跟踪（本机凭据不进入历史）
- [ ] 依赖目录、构建产物、测试报告、本地日志未被跟踪
- [ ] tracker 目录（`.scratch/`）已被跟踪——工单是工作记录，需要随仓库走
- [ ] `git status` 干净，无遗漏的未跟踪源文件
- [ ] 提交信息使用中文，说明这是交付基线

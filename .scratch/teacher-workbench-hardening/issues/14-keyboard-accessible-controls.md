# 14: 键盘可操作的账户菜单与通知列表

**What to build:** 全站没有任何无障碍属性，其中两处已经构成键盘陷阱：右上角的账户菜单是一个挂了点击事件的普通容器，键盘无法聚焦、回车打不开，等于没法退出登录；通知列表的每一行同样是"整行可点"的普通容器，只能靠鼠标阅读通知。做成：这两处都能用 Tab 聚焦、用回车/空格触发，并有对屏幕阅读器可读的名称。

**Blocked by:** None（可立即开始）

**Status:** ready-for-agent

- [ ] 账户菜单可通过键盘聚焦，回车或空格可展开，展开后可用键盘选择"退出登录"
- [ ] 通知列表项可通过键盘逐条聚焦，回车可打开详情
- [ ] 可聚焦元素有清晰的聚焦态样式（可见的焦点环）
- [ ] 图标类交互元素有可读的文本名称，屏幕阅读器不只念出"按钮"
- [ ] 鼠标操作体验与外观不变
- [ ] 新增组件测试：断言这两处可被键盘聚焦并触发
- [ ] 全量测试与类型检查保持绿色

# 04: 成果编辑不再覆盖手填分值

**What to build:** 教师登记教科研成果时可以在分值栏填写自定义分值。此后仅修改标题、角色、日期、说明等其它字段时，这个自定义分值必须保持不变。当前任何一次编辑都会把分值重置为"按级别自动折算"的默认值，属于静默数据丢失——用户改个错别字就丢了自己的评分。

**Blocked by:** None（可立即开始）

**Status:** done

- [x] 只修改成果的名称/角色/取得日期/说明时，原有分值完全不变
- [x] 编辑中显式改动了级别、且未手填分值时，分值按新级别自动折算
- [x] 编辑中显式手填了分值时，以手填值为准
- [x] 新增单元/集成测试覆盖以上三种情况（`apps/api/test/achievement.test.ts` 新增 3 条）
- [x] 全量测试与类型检查保持绿色（API 包 8 个测试文件全通过，`typecheck` exit 0）

**实现说明：** 分值只在"显式传了分值"或"显式改了级别"时才重算，其余情况不动该列。先写测试见其失败（`expected 3 to be 42`），再改实现转绿。

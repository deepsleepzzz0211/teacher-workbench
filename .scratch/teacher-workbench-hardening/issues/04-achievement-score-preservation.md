# 04: 成果编辑不再覆盖手填分值

**What to build:** 教师登记教科研成果时可以在分值栏填写自定义分值。此后仅修改标题、角色、日期、说明等其它字段时，这个自定义分值必须保持不变。当前任何一次编辑都会把分值重置为"按级别自动折算"的默认值，属于静默数据丢失——用户改个错别字就丢了自己的评分。

**Blocked by:** None（可立即开始）

**Status:** ready-for-agent

- [ ] 只修改成果的名称/角色/取得日期/说明时，原有分值完全不变
- [ ] 编辑中显式改动了级别、且未手填分值时，分值按新级别自动折算
- [ ] 编辑中显式手填了分值时，以手填值为准
- [ ] 新增单元/集成测试覆盖以上三种情况
- [ ] 全量测试与类型检查保持绿色

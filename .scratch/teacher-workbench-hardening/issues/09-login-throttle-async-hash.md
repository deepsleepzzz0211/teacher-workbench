# 09: 登录防爆破与异步口令校验

**What to build:** 登录接口没有任何频率限制，密码可以无限尝试；同时口令校验用的是同步实现，每次尝试都会阻塞事件循环。两者叠加等于给了一个廉价的 CPU 拒绝服务面，也让暴力破解变得可行。做成：同一来源的登录尝试有频率上限，超限返回 429；口令校验改为异步，不阻塞其它请求。

**Blocked by:** None（可立即开始）

**Status:** ready-for-agent

- [ ] 同一来源在短时间内超过阈值后，登录请求返回 429 并给出可读提示
- [ ] 阈值内正常登录不受影响，正确凭据仍能通过
- [ ] 口令校验不再同步阻塞事件循环（校验期间其它请求可正常响应）
- [ ] 限流不泄漏账号是否存在：被限流时不区分用户是否存在
- [ ] 新增测试覆盖：连续失败触发 429、限流不影响正常登录
- [ ] 全量测试与类型检查保持绿色

# 11: 应用级错误边界

**What to build:** 现在任何页面在渲染中抛错，整个应用会卸载成白屏——用户只看到一片空白，没有提示、无法返回、只能手动刷新，而且刷新后大概率复现。做成：任一页面崩溃时展示一个可恢复的错误页，说明发生了什么，并提供"返回工作台"的出口；应用外壳（侧边栏、顶栏）保持可用，用户能切换到其它正常页面继续工作。

**Blocked by:** None（可立即开始）

**Status:** ready-for-agent

- [ ] 单个页面渲染抛错时，不再整站白屏
- [ ] 错误页给出可读的中文说明与"返回工作台"操作
- [ ] 侧边栏与顶栏仍然可用，用户可以导航到其它页面
- [ ] 错误页展示的细节不泄漏内部实现信息（如堆栈），详细错误写入控制台
- [ ] 未发生错误时行为与外观完全不变
- [ ] 新增组件测试：用一个必定抛错的子组件验证错误页出现且导航可用
- [ ] 全量测试与类型检查保持绿色

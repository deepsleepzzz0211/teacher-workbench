# 05: 授课任务更新校验节次与周次区间

**What to build:** 创建授课任务时会拒绝"结束节次早于开始节次""结束周早于开始周"，但更新接口丢掉了这两条校验。结果是先建一条合法任务、再编辑一次，就能把非法区间写进库，进而污染课表展示与周学时分布。更新接口必须与创建接口口径一致。

**Blocked by:** None（可立即开始）

**Status:** ready-for-agent

- [ ] 通过更新接口提交"结束节次早于开始节次"时被拒绝，返回可读的中文错误提示
- [ ] 通过更新接口提交"结束周早于开始周"时被拒绝
- [ ] 仅改动其它字段（学时、地点、人数等）时正常通过
- [ ] 校验基于"合并后的最终值"而非仅补丁字段——即只改开始节次、使原结束节次变得非法时，同样被拒绝
- [ ] 新增回归测试覆盖以上四种情况
- [ ] 全量测试与类型检查保持绿色

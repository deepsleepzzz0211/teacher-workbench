# 06: 审批的权限与状态正确性

**What to build:** 调课/请假审批目前只要角色是院系管理员就能改任意申请的状态，没有任何状态守卫。三个后果要一并修掉：已审批过的申请能被再次翻转；管理员能审批自己提交的申请；任一院系管理员能看和批其他院系的申请，与"院系管理员"的定位不符。

**Blocked by:** None（可立即开始）

**Status:** ready-for-agent

- [ ] 只有"待审批"状态的申请可以被审批；对已通过或已驳回的申请再次审批被拒绝，并返回可读提示
- [ ] 提交人不能审批自己提交的申请，且该限制在提交人恰好也是管理员时同样生效
- [ ] 管理员的申请列表、待审批列表、首页待审批计数三处口径一致，都限定在本院系范围内
- [ ] 管理员在非本院系申请上的审批请求被拒绝
- [ ] 新增集成测试覆盖：重复审批、自审、跨院系三条路径
- [ ] 全量测试与类型检查保持绿色

# 23: 图表按需引入与路由懒加载

**What to build:** 图表库是整包引入的，且所有页面在入口处一次性静态导入，于是连登录页都要先下载整个图表库——用户还没登录就为图表付了流量和解析时间。做成：图表按需引入（只打包用到的图表类型与组件），页面按路由懒加载；登录页与首屏不再包含图表代码。用构建体积的前后对比作为证据。

**Blocked by:** None（可立即开始）

**Status:** ready-for-agent

- [ ] 图表库改为按需引入，只包含实际使用的图表类型与必要组件
- [ ] 页面按路由懒加载，访问某页时才加载该页代码
- [ ] 登录页不再加载图表相关代码（以构建产物的分包构成证明，而非口头断言）
- [ ] 首屏与登录页的传输体积相比改造前有明显下降，并给出前后数字
- [ ] 六个使用图表的页面照常渲染，图表交互（提示、图例、自适应）无回归
- [ ] 懒加载期间有加载态，不出现长时间空白
- [ ] 全量测试与类型检查保持绿色

# 18: 核心页测试补齐

**What to build:** 前端的组件测试只覆盖了通用卡片、标签、登录页和 404 共 18 条断言，而产品的招牌功能——授课任务的实时折算预览——没有任何测试；首页看板同样没有。更糟的是架构文档声称"组件测试覆盖工作量计算展示"，与事实不符。做成：这两处有真实的测试，文档声明与实际情况一致。

**Blocked by:** 02 CI 质量门

**Status:** ready-for-agent

- [ ] 有测试断言：选择课程与班级、填写学时与人数后，折算预览显示正确的系数与折算学时
- [ ] 有测试断言：改变人数跨越 40 人阈值时，班级规模系数随之变化
- [ ] 有测试断言：重复课次序大于 1 时，预览体现重复课系数
- [ ] 首页看板有测试断言：关键统计（折算学时、达成率、企业实践进度）按接口数据正确渲染
- [ ] 测试断言的是可观察的输出（屏幕上的文本/数值），而非内部实现细节
- [ ] 架构文档中关于测试覆盖的描述与实际一致
- [ ] 全量测试与类型检查保持绿色

# 12: 工作量变更后看板数据同步

**What to build:** 在"教学工作量"页新增、修改或删除授课任务与其它工作量之后，回到工作台首页，首页显示的折算学时与达成率仍是旧值——因为工作量页的写操作只刷新了自己页面的数据，没有刷新首页用的那份。用户会看到两个页面数字互相矛盾，且不知道哪个是对的。

**Blocked by:** None（可立即开始）

**Status:** ready-for-agent

- [ ] 新增授课任务后回到首页，总折算学时与达成率反映最新值
- [ ] 修改授课任务（如改总学时）后同理
- [ ] 删除授课任务后同理
- [ ] 新增 / 删除其它工作量后同理
- [ ] 失效范围与其它页面（成果、企业实践、待办、申请）保持一致的口径，不留特例
- [ ] 新增端到端用例：改工作量 → 切回首页 → 断言数字已更新
- [ ] 全量测试与类型检查保持绿色

# 高职院校教师工作台 — 需求规格说明书

> 版本：v1.0 · 交付件 · 面向高职（专科层次职业院校）专任教师的一体化个人工作台

## 1. 背景与问题

通过对职业教育政策文件、院校教师发展中心公开资料、教师工作量管理制度与一线教师日常事务的调研，归纳出高职专任教师在个人事务层面的四类高频痛点：

| 编号 | 痛点 | 具体表现 |
|---|---|---|
| P1 | **重复填报** | 课表、课时、科研、培训等数据分散在教务、科研、人事多个系统，教师需反复手工填写同一份信息 |
| P2 | **工作量核算繁琐** | 理论课、理实一体课、实训课、顶岗实习指导的折算系数不同，还涉及班级规模、重复授课，手工算易错、难自证 |
| P3 | **材料散落** | 论文、课题、竞赛、专利、教材、培训证书散落在本地文件夹，职称评审/绩效考核前集中"翻找" |
| P4 | **"双师型"要求难跟踪** | 政策要求教师每 5 年赴企业集中实践累计 6 个月，个人无法直观看到自己还差多少 |

政策依据要点（调研摘录）：

- 教育部《职业教育"双师型"教师基本标准（试行）》推动各地开展"双师型"教师认定。
- 上海市教委《深化人才培养模式全过程改革推动上海高等职业教育全面适配产业发展的工作方案》（2026）：明确"推动教师每 5 年赴企业集中实践 6 个月"。
- 教育部等四部门《职业学校兼职教师管理办法》，以及国家级职业教育教师教学创新团队、名师名匠培养计划等，均要求教师个人有可追溯的发展档案。
- 院校教师发展中心评估指标中普遍包含"建立教师个人业务档案""建设资源平台""组织教学竞赛与培训"。

结论：教师端最刚性的诉求是 **"一次录入、自动汇总、随时可导出"** 的个人教学工作台，而非再增加一个审批系统。

## 2. 产品定位

**一句话**：面向高职专任教师的个人工作台，把"课表—工作量—教科研成果—企业实践—审批—通知待办"收敛到一个界面，数据一次录入、自动折算、实时汇总。

**不做**（明确边界，避免范围蔓延）：排课算法、学生端、学籍管理、财务、招生、在线教学平台。本系统只服务"教师个人"这一个角色视角，附带一个轻量的院系管理视角用于审批。

## 3. 角色

| 角色 | 说明 | 权限 |
|---|---|---|
| `teacher` 专任教师 | 主用户 | 管理自己的全部数据；发起调课/请假申请 |
| `dept_admin` 院系管理员 | 教研室主任 / 教学秘书 | 在教师权限之上，可审批本院系申请、发布通知 |

## 4. 功能需求

### FR-01 认证与账号
- 用户名 + 密码登录，签发 JWT（含 `sub`/`role`）。
- 登出（前端清理令牌）。
- `GET /me` 返回当前教师档案（姓名、工号、院系、职称、角色）。
- 未认证访问受保护接口返回 401；角色不足返回 403。

### FR-02 工作台首页（看板）
聚合展示，一次请求返回：
- **今日课程**：当天全部授课任务（按节次排序）。
- **待办事项**：未完成事项，按截止日期升序。
- **最新通知**：最近 5 条，标注已读/未读。
- **本学期工作量概览**：已折算学时、基本工作量要求、达成率。
- **教科研成果统计**：按类别计数。
- **企业实践进度**：近 5 年累计天数 / 政策要求天数（180 天）。

### FR-03 我的课表
- 按学期、按周展示课表（周一至周日 × 节次网格）。
- 支持查看今日课程、切换学期。
- 授课任务包含：课程、班级、上课地点、星期、节次、周次范围、总学时、课程类型。

### FR-04 教学工作量（核心）
- **录入**授课任务：课程名、课程类型、班级、班级人数、总学时、重复授课次序。
- **自动折算**：`折算学时 = 总学时 × 课程类型系数 × 班级规模系数 × 重复课系数`。
- **其他工作量**：顶岗实习指导、毕业设计指导、技能竞赛指导、社会培训、教研活动等按条目录入数量并折算。
- **汇总视图**：按学期汇总（总折算学时、分类型构成）、按月度趋势。
- **达成率**：与学期基本工作量（默认 240 折算学时）对比，展示完成百分比。
- **规则可自证**：前端展示每条记录所用的系数与计算过程，教师可复核。

**折算规则（本系统口径，可配置）**

| 因子 | 取值 |
|---|---|
| 课程类型系数 | 理论课 `1.0`；理实一体课 `1.1`；实训课 `1.2`；顶岗实习 `1.5` |
| 班级规模系数 | 班级人数 ≤ 40 → `1.0`；> 40 → `min(1.3, 1 + (人数 − 40) × 0.01)` |
| 重复课系数 | 同一学期同一教师同一课程第 1 次授课 `1.0`；第 2 次及以后 `0.9` |
| 学期基本工作量 | `240` 折算学时 |

### FR-05 教科研成果
- 六类成果登记：论文、课题（教科研项目）、竞赛获奖、专利/软著、教材/著作、培训进修。
- 字段：类别、标题、级别（国家级/省级/市厅级/校级）、本人角色、日期、分值、说明。
- 列表支持按类别、级别、时间筛选；按类别/级别聚合统计。

### FR-06 企业实践（"双师型"）
- 登记实践记录：企业名称、岗位、起止日期、天数、内容说明。
- 自动计算**近 5 年累计实践天数**，与政策要求 `180 天` 对比，展示进度条与差额。

### FR-07 调课 / 请假申请
- 教师发起申请：类型（调课/请假）、关联课程班级、原时间、目标时间、事由。
- 状态流转：`pending` → `approved` / `rejected`（含审批意见与审批人）。
- 教师查看自己的申请列表与状态；`dept_admin` 可查看待审批列表并审批。

### FR-08 通知公告
- 列表展示（置顶优先、时间倒序），分页。
- 详情查看，打开即标记已读；列表显示未读数。
- `dept_admin` 可发布通知。

### FR-09 待办事项
- 增删改查；字段：标题、截止日期、优先级、状态、关联类型。
- 支持标记完成/未完成。

## 5. 非功能需求

| 编号 | 要求 |
|---|---|
| NFR-01 | 前后端分离：前端 SPA 通过 REST/JSON 调用后端 |
| NFR-02 | 数据库使用 PostgreSQL 15；所有表结构经版本化 SQL 迁移管理 |
| NFR-03 | 后端为 TypeScript，接口入参出参以 Zod Schema 校验，Schema 与前端共享 |
| NFR-04 | 测试驱动开发：领域逻辑与接口集成测试先于实现；关键路径具备端到端测试 |
| NFR-05 | 一键启动：`pnpm setup && pnpm dev` 即可拉起数据库迁移、种子数据、后端与前端 |
| NFR-06 | 演示数据完整：登录后即见真实感数据，无需手工造数 |
| NFR-07 | 界面使用 Ant Design 5，中文界面，桌面端优先（≥1280px） |

## 6. 验收标准

1. `pnpm install` 后 `pnpm setup` 能建表并灌入种子数据且无报错。
2. `pnpm test` 全绿（后端领域逻辑单测 + 接口集成测试 + 前端组件测试）。
3. `pnpm dev` 可同时启动 API（:3000）与 Web（:5173），浏览器可登录。
4. 使用演示账号登录后，看板显示今日课程、工作量达成率、成果统计、企业实践进度。
5. `pnpm e2e` 端到端用例通过，覆盖：登录 → 看板 → 新增授课任务并校验收割折算 → 新增科研成果 → 提交调课申请 → 管理员审批 → 通知已读。
6. `README.md` 说明架构、启动方式、演示账号、测试命令。
